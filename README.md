# Doom Emacs configuration

Personal [Doom Emacs](https://github.com/doomemacs/doomemacs) configuration for
editing, writing, and research workflows.

Place or symlink this repository at `~/.config/doom`, then sync it:

```sh
make sync
```

Run `make update` to update packages. Review `config.el` before use because it
contains machine-specific fonts and paths.
